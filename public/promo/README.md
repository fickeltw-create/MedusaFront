# Promo Images Directory

Place all promotion images here. The expected filenames are:

- student-house-promo.jpg (for maison-etudiante)
- tiny-house-promo.jpg (for tiny-house)
- apartment-house-promo.jpg (for maison-appartement)
- family-house-promo.jpg (for maison-familiale)
- space-capsule-promo.jpg (for space-capsule)

The code will automatically use these images once they're placed in this directory. If an image is not found, it falls back to the existing house image from the catalogue.
